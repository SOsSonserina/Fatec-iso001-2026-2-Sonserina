# Aula 04 - Modelo de Processos

Apresenta a modelagem dos principais processos da solução. Foram identificados os componentes da aplicação, suas responsabilidades, forma de execução, dependências e mecanismos de controle.

Também são descritos o ciclo de vida dos processos, possíveis cenários de falha e estratégias de monitoramento e recuperação, utilizando como base o projeto da disciplina.

## Arquivos

- `docs/04-processos.md` - inventário dos componentes, ciclo de vida e análise de falhas.
- `diagrams/runtime-processes.mmd` - diagrama dos processos e dependências operacionais da solução.
